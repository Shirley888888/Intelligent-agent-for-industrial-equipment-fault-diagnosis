# 实验报告：ETTh1 未来 24h 油温预测（课后实验·任务 1）

## 1. 实验目标

使用 ETTh1 数据，比较 Baseline / Linear / MLP / CNN / LSTM 模型在未来 24 小时 OT（变压器油温）预测上的表现，并完成至少 3 次结构变化实验：
- MLP hidden=64 → 128
- CNN kernel=3 → 5
- LSTM layers=1, hidden=32 → layers=2, hidden=64

另补测 3 个训练超参（lr / batch_size / epochs），观察其对各模型的影响。

## 2. 数据处理

- 输入：过去 96 小时，7 个变量（OT + f1/f2/f3/f4/f5/f6）
- 输出：未来 24 小时 OT
- 归一化：z-score，只用训练段拟合，避免泄漏
- 划分：严格按时间顺序 70/15/15（训练/验证/测试）
- 指标：MAE / MSE 均为还原到原始油温单位后计算

## 3. 实验设置

- 优化器 Adam，损失 MSELoss，lr=0.001，batch_size=256（可调，见 config.yaml）
- r1 为快速验证：epochs=20；r2 起进入完整 epochs=100 实验，并逐步完成 3 次结构变化实验
- 每轮全量重跑 5 个模型；loss 曲线见 `outputs/figures/`

> **重要勘误（r7 后全量重跑）**：发现并修复了 `train.py` 中 best-权重加载 bug——
> `model.state_dict()` 返回的是**参数引用**而非拷贝，被后续训练 in-place 污染，
> 导致测试评估实际使用了**最后一个 epoch** 的权重而非验证集最优 epoch 的权重。
> 已改为深拷贝，并重跑 r1–r7 全部轮次。下表数值均为修复后（best-epoch 权重）的结果；
> val loss 曲线、best_epoch、best_val_loss 不受影响（本计算正确）。

## 5. 结论与讨论

### r1（epochs=20 快速验证）

- **改了什么**：训练轮数设为 20，保持默认结构超参（MLP hidden=64/layers=2、CNN kernel=3/channels=32、LSTM 1层/hidden=32），完成 5 模型全流程。
- **模型哪里变了**：无结构变化；验证训练、验证、测试划分、z-score 归一化、逐 epoch 记录 loss、自动保存最优验证权重等流程是否正确。
- **结果如何变化/观察**：
  - **Baseline 依然强劲**：MAE 仅 2.58，说明该小数据集具有强自相关性，persistence 基线是很难超越的参照。
  - **Linear 严重过拟合**：训练 loss 降到 0.02，但验证 loss 在 epoch 1 后迅速上升并稳定在 1.1 左右，说明 672 维输入线性模型在 966 个训练样本上容量过大；其 best_epoch=1 意味着"最优"权重几乎未训练。
  - **MLP 最快收敛**：训练 loss 在 3-4 个 epoch 内接近 0，最佳验证 epoch=4，之后开始过拟合；best-epoch 权重训练不足，test 上偏大。
  - **LSTM 最稳定**：验证 loss 曲线平滑，在 epoch 13 达到最低，随后轻微反弹，综合 MAE/MSE 为学习模型中最优。
  - **CNN 中等**：验证 loss 在 epoch 13 最低，随后回升，结构与 kernel 尺寸仍需调优。

### r2（完整 100 epochs + MLP hidden 64→128）

- **改了什么**：epochs 20→100（所有模型），MLP hidden 64→128（第一次结构变化，参数量 48,792→105,752，容量提升约 2.2 倍）。
- **模型哪里变了**：MLP 每层隐藏单元翻倍，可拟合更复杂的非线性关系；其余模型结构不变。
- **结果如何变化**（对比 r1）：
  - **LSTM 受益最大**：MAE 9.22→8.37（↓9%）、MSE 119.49→98.04（↓18%），best_epoch 从 13 移到 29，说明此前 20 epoch 未充分收敛；100 epoch 后 LSTM 是所有学习模型中唯一逼近 Baseline（MAE 2.58）的。
  - **MLP（hidden=128）**：best_epoch 仍在 epoch 3（几乎未训练），修复后 best-epoch 权重在 test 上反而比 r1 差（16.61→23.03）。原因：更大容量的 MLP 在 lr=0.001 下 1-3 个 epoch 即过拟合，val 最低点出现得过早，对应权重欠训练、在 test 时段泛化差。这暴露了 early stopping 在此类任务上的局限（见 r5 讨论）。
  - **CNN**：100 epoch 下 best_epoch 仍为 13（val 在 0.12 见底后一路升至 0.57），过拟合严重。
  - **Linear 依旧过拟合**：best_epoch=1，100 epoch 无帮助，验证 loss 长期停在 1.1 附近。
- **复现性改进**：train.py 加入每模型独立 seed，r2 与 r3 中同配置的 Linear/MLP/LSTM 结果完全一致（差异为 0）。

### r3（CNN kernel 3→5）

- **改了什么**：仅改 CNN 卷积核 kernel 3→5（感受野扩大，参数量 1,496→1,944），其余（epochs=100、MLP hidden=128、LSTM 1/32）保持 r2 不变。
- **模型哪里变了**：CNN 每次卷积覆盖 5 个时间步（原 3 步），可捕捉更长时间跨度的局部时序模式。
- **结果如何变化**（CNN 对比 r2，其余模型与 r2 完全一致）：
  - **CNN 小幅改善**：MAE 15.86→15.20（↓4%）、MSE 343.61→335.72（↓2%），best_epoch 13→11。增大感受野略微缓解过拟合，但验证 loss 仍在 best_epoch 后持续攀升（0.16→0.59），说明 CNN 的根本问题不在 kernel 尺寸，而在于缺乏正则化（dropout/weight decay/early stopping）。
  - **Linear/MLP/LSTM 与 r2 完全相同**（31.32/23.03/8.37）：验证了 per-model seed 的可复现性，CNN 结构变化对其他模型零串扰。

### r4（LSTM 1层/hidden32 → 2层/hidden64）

- **改了什么**：仅改 LSTM：层数 1→2、hidden 32→64（参数量 6,040→53,528，约 8.9 倍），其余（epochs=100、MLP hidden=128、CNN kernel=5）保持 r3 不变。
- **模型哪里变了**：LSTM 加深加宽，两层堆叠可建模更高阶的时间依赖；代价是训练时间从 ~16s 增至 ~47s（CPU）。
- **结果如何变化**（LSTM 对比 r3，其余模型与 r2/r3 完全一致）：
  - **LSTM 明显提升**：MAE 8.37→5.46（↓35%）、MSE 98.04→40.81（↓58%），best_val_loss 0.038→0.023，best_epoch 29→30。加深加宽后 LSTM 成为全部学习模型中绝对最优，并大幅逼近 Baseline（MAE 2.58）。
  - **可复现性再次确认**：Linear/MLP/CNN 与 r2/r3 完全相同（31.32/23.03/15.20），LSTM 结构变化对其他模型零串扰。

### r5（lr 0.001 → 0.0001）

- **改了什么**：仅将训练超参 `lr` 从 0.001 降到 0.0001（降 10 倍），结构配置保持 r4（MLP 128、CNN k5、LSTM 2/64、epochs=100、batch=256）不变。
- **模型哪里变了**：无结构变化；优化器步长缩小，参数更新更保守，理论上训练更慢但更稳、过拟合更晚出现。
- **结果如何变化**（对比 r4，结构完全一致）：
  - **CNN 改善最大**：MAE 15.20→13.33（↓12%）、MSE 335.72→262.92（↓22%），best_epoch 11→94。小步长让 CNN 首次得到充分训练（val 最低点从 epoch 11 移到 94），best-epoch 权重质量显著提升。
  - **MLP 明显改善**：MAE 23.03→15.33（↓33%）、MSE 745.81→346.82（↓54%），best_epoch 3→21。过拟合点被延后，best-epoch 权重不再是"几乎未训练"的权重。
  - **Linear 明显改善**：MAE 31.32→23.29、MSE 1524.38→881.54，best_epoch 1→12，但 train 0.03 vs val 1.06 仍严重过拟合，结构性问题（672 维输入 vs 966 样本）无法靠 lr 解决。
  - **LSTM 反而大幅变差**：MAE 5.46→7.95、MSE 40.81→86.44，best_epoch 30→89。lr=0.0001 下 LSTM 的 val 最低点（0.019@89，甚至低于 r4 的 0.023@30）对应权重在 test 时段泛化很差——**验证集最优 ≠ 测试集最优**，时间序列验证/测试时段存在分布偏移。
- **结论**：小 lr 对 Linear/MLP/CNN 是正收益（best-epoch 延后、权重更成熟），对 LSTM 却是负收益；同时暴露了 early stopping 在时间序列划分下的不稳定性。

### r6（batch_size 256 → 128）

- **改了什么**：仅将 `batch_size` 从 256 减半到 128（梯度更噪声、更新更频繁），lr 保持 r5 的 0.0001，结构保持 r4 不变。
- **模型哪里变了**：无结构变化；每个 mini-batch 样本变少，梯度估计噪声增大，等效引入一定的隐式正则。
- **结果如何变化**（对比 r5，lr 相同、结构相同）：
  - **各模型几乎持平**：LSTM 7.95→7.97（±0.2%）、CNN 13.33→13.34（±0.1%）、MLP 15.33→15.41（+0.5%）、Linear 23.29→24.01（+3%）。
  - **Linear 小幅变差**：best_epoch 12→6，更强的梯度噪声让本已过拟合的 Linear 更早见顶。
  - **其余模型不受 batch 影响**：best-epoch 权重的 test 表现基本无变化，说明在 lr=0.0001 下 batch 大小对收敛质量影响有限。
- **结论**：batch 减半在本任务中没有带来此前（修复前数据）看到的"隐式正则正收益"，各模型表现基本持平。

### r7（epochs 100 → 200）

- **改了什么**：仅将 `epochs` 从 100 翻倍到 200，lr=0.0001、batch=128 保持 r6 不变，结构保持 r4 不变。
- **模型哪里变了**：无结构变化；训练轮数翻倍。
- **结果如何变化**（对比 r6）：**五个模型的 MAE/MSE/best_epoch 与 r6 完全一致**。原因：best-epoch 在训练早期（Linear@6、MLP@11、CNN@49、LSTM@46）即被选定，后 100 epoch 的额外训练对"验证集最优权重"没有贡献——印证了 early stopping 的机制：多余 epochs 无效，只会白白增加训练时间（LSTM 47s→112s）。
- **结论**：在已用验证集做 early stopping 的前提下，加大 epochs 是纯负收益（无改善且耗时翻倍）。若想利用更多训练，应同时配合 lr 衰减或正则化，而不是简单加 epochs。

### 三次结构变化实验总结

| 结构变化 | 参数量 | MAE | MSE | 结论 |
|----------|--------|-----|-----|------|
| MLP hidden 64→128（r1→r2） | 48,792→105,752 | 16.61→23.03 | 390.08→745.81 | 更大容量 + 过早的 best-epoch → test 上不稳定（r1/r2 同时含 epochs 20→100 变化，对比不纯） |
| CNN kernel 3→5（r2→r3） | 1,496→1,944 | 15.86→15.20 | 343.61→335.72 | 增大感受野小幅改善，但仍过拟合，需正则化 |
| LSTM 1/32→2/64（r3→r4） | 6,040→53,528 | 8.37→5.46 | 98.04→40.81 | 加深加宽 LSTM 改善最明显（MAE↓35%、MSE↓58%），逼近 Baseline |

### 训练超参补测总结

| 超参变化 | 受影响最大的模型 | 结论 |
|----------|------------------|------|
| lr 0.001→0.0001（r4→r5） | CNN（13.33，↓12%）、MLP（15.33，↓33%）、LSTM（7.95，↑46% 变差） | 小 lr 让 Linear/MLP/CNN 的 best-epoch 后移、权重更成熟而改善；LSTM 的 val 最优权重在 test 泛化差而变差 |
| batch 256→128（r5→r6） | 各模型基本持平 | 在本任务下 batch 减半无明显收益/损失 |
| epochs 100→200（r6→r7） | 无（结果与 r6 完全一致） | 已有 early stopping，多余 epochs 纯耗时无收益 |

- **最终结论**：
  1. LSTM（2层/64）是唯一逼近可用水平的模型（最优 MAE 5.46，r4 配置 lr=0.001/batch=256/epochs=100），三次结构变化中提升最大。
  2. 所有学习模型仍远差于 Last-Value Baseline（MAE 2.58）——ETTh1 强自相关性 + 小样本使 persistence 难以被超越，这也是该数据集的公开共识。
  3. 训练超参补测未找到优于 r4 的组合；小 lr 有利于 Linear/MLP/CNN 的 best-epoch 泛化，但以 LSTM 的明显退化为代价。
  4. **重要方法学发现**：在时间序列 70/15/15 划分下，"验证集最优 epoch 权重"不一定在测试集上最好（r5 LSTM 最典型，val 最低但 test 最差）。若追求稳定的测试表现，可考虑"按 val 最优选 epoch，再用全部 train+val 重训"或对 val/test 时段做更严格的交叉验证。
